# پورتفولیوی پارسا رحمانی

پورتفولیوی شخصی و رزومه آنلاین پارسا رحمانی، با تمرکز بر توسعه نرم‌افزار، مهندسی فول‌استک و هوش مصنوعی.

## فناوری‌ها

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## اجرا

```bash
npm install
npm run dev
```

سپس برنامه در محیط توسعه اجرا می‌شود.

## ساختار

این پروژه یک صفحه اصلی تعاملی و واکنش‌گرا دارد و بخش‌های معرفی، تجربه کاری، مهارت‌ها، پروژه‌ها، تحصیلات و ارتباط را شامل می‌شود.
